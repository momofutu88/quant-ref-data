## 四、基础设施现状（零手工管线）

- **采集**：GitHub 私有仓库 `momofutu88/tds-data`，Actions 每天 09:00（北京时间）自动跑，5 个带单员一次全采，数据自动 commit 回仓库 + artifact 留档 90 天
- **新增带单员**：只需要拿到 ta 的分享链接里的项目 ID（一串数字），加进清单即可，**不需要录屏、不需要截图、不需要梯子**——采集在美国 GitHub 服务器上完成
- **你本地需要的全部装备**：
  - 手机：能打开币安 App 复制带单员分享链接（已有 ✅）
  - 电脑：什么都不用装，浏览器能打开 github.com 即可看数据（家里电脑 ✅ 够用）
  - 网络：只要你能登录 GitHub 网页就够；若 github.com 打不开，装一个 Clash 类工具（Windows：Clash Verge；Mac：ClashX），订阅你现成的机场节点，仅访问 github.com 时开启
  - **不需要**：交易所 API Key、币安登录态、任何账号密码——全部数据来自公开接口
